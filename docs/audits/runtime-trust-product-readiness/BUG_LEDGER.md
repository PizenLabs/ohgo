test fails on the old behavior. **Partially fixed** means the defect is now
disclosed or bounded but the full capability is still a documented limitation.
**Open** means the defect remains.

## Documented limitations (not defects disguised as fixes)

- **Multiple sibling Go modules** are inventoried and parsed, but imports are
  not resolved across module boundaries. The ambiguity is now explicit.
- **Non-Go semantic resolution** remains syntax-level. Tree-sitter adapters do
  not perform type resolution, overload resolution, or dispatch.
- **GRY edge verification** is not implemented for every relationship. The
  adapter now represents an endpoint-current edge as `UNVERIFIED`, never as
  `CURRENT`; a future provider that supplies a current per-edge generation can
  upgrade it.
- **Claim grounding** is general for explicit code entities but still not a
  semantic parser. A plausible unsupported claim that names no code entity, or
  that names an observed entity while asserting a behavior the observation does
  not establish, can still pass.
- **Streaming isolation** covers exact runtime-authored lines and the fixed
  directives. A model can invent its own prose that resembles runtime state
  without matching a runtime line; that is model-authored text, not a leaked
  directive.
